## Reporting a Vulnerabile 

**Zero Advertising & No Data Selling:** EduGenius AI never displays third-party advertisements or sells student personal information.
- **Client & Server Isolation:** Passwords use salted PBKDF2 cryptographic hashing. Sensitive operations are routed server-side without exposing API keys to the browser client.
